# QueryData API Interface Reference

The `QueryData` API interface allows querying a database using natural language prompts by translating them into SQL, executing the SQL, and returning a natural language answer along with the generated query and query results. It uses context sets to understand database schemas and domain-specific knowledge.

## API Endpoint

```http
POST https://geminidataanalytics.googleapis.com/v1beta/projects/{projectId}/locations/{locationId}:queryData
```

## Authentication

Authentication is performed using OAuth 2.0. The request must include an `Authorization: Bearer` header with an access token (e.g., from `gcloud auth application-default print-access-token`).

## Request Structure

The request payload is a JSON object with the following structure:

- `prompt` (string, required): The natural language question or instruction.
- `context` (object, required): Contextual information about the data source.
  - `datasourceReferences` (object): A mapping of datasource types to their references.
    - `alloydb` (object): Reference to an AlloyDB datasource.
      - `databaseReference` (object): Database details.
        - `projectId` (string): The Google Cloud project ID.
        - `region` (string): The region where the AlloyDB cluster is located.
        - `clusterId` (string): The ID of the AlloyDB cluster.
        - `instanceId` (string): The ID of the primary AlloyDB instance.
        - `databaseId` (string): The name of the database.
      - `agentContextReference` (object): Reference to a predefined context set that describes the database schema, rules, and examples.
        - `contextSetId` (string): The full resource name of the context set, formatted as `projects/{project}/locations/{location}/contextSets/{contextSetId}`.
- `generationOptions` (object, optional): Options to customize the output.
  - `generateNaturalLanguageAnswer` (boolean): Whether to generate a conversational answer.
  - `generateQueryResult` (boolean): Whether to execute the query and return the result rows.
  - `generateExplanation` (boolean): Whether to generate an explanation of how the query was constructed.

### Example Request (curl)

```bash
curl -X POST "https://geminidataanalytics.googleapis.com/v1beta/projects/${GOOGLE_CLOUD_PROJECT}/locations/us-central1:queryData" \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  -d "{
  \"prompt\": \"How many properties are currently for sale in San Diego?\",
  \"context\": {
    \"datasourceReferences\": {
      \"alloydb\": {
        \"databaseReference\": {
          \"projectId\": \"${GOOGLE_CLOUD_PROJECT}\",
          \"region\": \"${ALLOYDB_LOCATION}\",
          \"clusterId\": \"${ALLOYDB_CLUSTER}\",
          \"instanceId\": \"${ALLOYDB_INSTANCE}\",
          \"databaseId\": \"${ALLOYDB_DATABASE}\"
        },
        \"agentContextReference\": {
          \"contextSetId\": \"${QUERYDATA_CONTEXTSET}\"
        }
      }
    }
  },
  \"generationOptions\": {
    \"generateNaturalLanguageAnswer\": true,
    \"generateQueryResult\": true,
    \"generateExplanation\": true
  }
}"
```

## Response Structure

The response is a JSON object containing:

- `generatedQuery` (string): The SQL query generated by the model.
- `intentExplanation` (string): A step-by-step explanation of the query logic and structure.
- `queryResult` (object): The result of executing the SQL query.
  - `columns` (array of objects): Names and data types of returned columns.
  - `rows` (array of objects): Rows representing the query result set.
  - `totalRowCount` (string): Total number of rows returned.
- `naturalLanguageAnswer` (string): The conversational response summarizing the query results.

### Example Response

```json
{
  "generatedQuery": "SELECT COUNT(\"p\".\"property_id\") AS \"property_count\" FROM \"properties\" AS \"p\" INNER JOIN \"cities\" AS \"c\" ON \"p\".\"city_id\" = \"c\".\"city_id\" WHERE \"c\".\"city_name\" = 'San Diego' AND \"p\".\"listing_status\" IS NOT NULL AND UPPER(\"p\".\"listing_status\") = 'FOR SALE';", 
  "intentExplanation": "I resolved the query by joining the 'properties' and 'cities' tables on 'city_id'. I filtered for the city name 'San Diego' and ensured that the listing status is 'FOR SALE' (case-insensitively) and not null. Finally, I used the COUNT function to aggregate the total number of matching properties.", 
  "queryResult": {
    "columns": [
      {
        "name": "property_count",
        "type": "INT8"
      }
    ],
    "rows": [
      {
        "values": [
          {
            "value": "0"
          }
        ]
      }
    ],
    "totalRowCount": "1"
  },
  "naturalLanguageAnswer": "There are 0 properties currently for sale in San Diego."
}
```
